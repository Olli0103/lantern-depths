A word to the curious

Select a marker or a nearby object to see its actions. Select an item in your satchel to use it with another object.

The command line understands the original game’s commands. Try look, inventory, or examine mailbox. Unusual ideas are welcome.

Use Tab to move between controls and Enter to activate them. Escape cancels an item-to-object action or closes a dialog. The Journal button folds the text without hiding the command line. Up/Down in the command line recalls recent commands. Undo restores your previous command, journal and discovered routes together; the last 20 commands are kept during this session. Use Settings → Saved adventures for additional slots and file export/import.
