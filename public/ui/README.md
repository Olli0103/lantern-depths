# Lantern Depths UI vectors

Original lightweight vector UI assets for the Lantern Depths browser shell.

They provide the decorative frame, compass rose, interaction marker, journal botanical ornament, page texture, and reusable line-icon symbols used by `src/ui.css` and `index.html`.

The assets were produced specifically for this project and contain no commercial Zork packaging, logos, screenshots, or third-party artwork. They are interface chrome only; game environment paintings remain in `public/art` with their existing provenance documentation.
