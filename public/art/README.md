# Original environment paintings

Generated for Lantern Depths on 2026-09-08 using the built-in image-generation tool. Google Imagen was not used. The final prompts are recorded in `docs/ART-PROMPTS.md`.

This does not grant franchise trademarks or rights in third-party material. Purely generated material may not attract copyright in some jurisdictions.

The initial six paintings are environment plates. The living-house update adds `objects-atlas.png` (one transparent 4×2 sprite sheet), `west-house-open.png`, `behind-house-open.png` and `kitchen-closed.png`. The sheet is used intact via CSS cells, without raster post-processing. These cover initial opening interactions, not every possible object state in the full game.
